1.2. Программы для сборки мембранных систем¶

Существует множество программ, с помощью которых можно собрать мембранную систему:

  • CHARMM-GUI Membrane Builder https://www.charmm-gui.org/?doc=input/membrane.bilayer

    • Наиболее популярная программа для сборки систем "белок в мембране"
    • Автоматизированный веб-интерфейс
    • Поддержка множества типов мембран: плоские моно/бислои, мицеллы, липидные нанодиски, везикулы
    • Большая библиотека липидов и детергентов (сотни типов) и готовые входные файлы для основных MD‑пакетов (CHARMM, AMBER, OPLS и др.).​

  • MemBuilder https://maayanlab.cloud/datasets2tools/landing/tool/MemBuilder

    • Веб‑интерфейс для сборки бислоев под GROMACS; поддержка асимметричных мембран
    • Выдает топологии и координаты системы после минимизации энергии.
    • Встроенная база ~18 липидов (меньше, чем у CHARMM-GUI) и несколько силовых полей (GROMOS96 варианты и Slipid/Amber); опционально добавляет воду и ионы до нужной ионной силы

  • HTMD Membrane Builder https://software.acellera.com/htmd/tutorials/MembraneBuilder.html

    • Сборка мембраны с помощью скриптов: построение бислоя в Python, задание размеров по XY и состава верхнего/нижнего листков словарями; есть просмотр и автоматическая минимизация/уравновешивание.
    • Расширяемость: добавление новых липидов (из PDB) и CSV с APL/толщиной/головной группой;
    • Упор на программируемые пайплайны.

  • Curved Membrane (Cmem) Builder https://cmembuilder.com/

    • Специализация: автоматическая генерация изогнутых мембран и комплексов «белок–мембрана» для крупнозернистого (coarse grain) молекулярной динамики (CS-MD, силовое поле Martini), с заданной кривизной

  • И другие (например, наш внутренний программный пакет Импульс, используемый в нашей лаборатории)...

2. Практика¶

2.1. Модельный белок: MELLITIN¶

  • Мелиттин — основной компонент пчелиного яда, составляет примерно 35–50% сухой массы яда.​

  • Представляет собой катионный амфифильный пептид из 26 аминокислот с молекулярной массой около 2840 Да.​

Структура меллитина

Hong J, Lu X, Deng Z, Xiao S, Yuan B, Yang K. How Melittin Inserts into Cell Membrane: Conformational Changes, Inter-Peptide Cooperation, and Disturbance on the Membrane. Molecules. 2019;24(9):1775. https://doi.org/10.3390/molecules24091775.

  • Обладает свойствами детергента: связывается с мембранами, образует поры, повышает проницаемость и вызывает лизис клеток (в т. ч. гемолиз).​

  • Проявляет антибактериальные, противовирусные, противогрибковые и противоопухолевые эффекты, но действует неселективно и очень цитотоксичен.​

  • Рассматривается как перспективный компонент для противоопухолевой терапии и адъювантной иммунотерапии, однако требует модификаций для снижения токсичности.

Предполагаемая модель взаимодействия мелиттина с мембраной

Zhang HQ, Sun C, Xu N, Liu W. "The current landscape of the antimicrobial peptide melittin and its therapeutic potential." Front. Immunol. 2024;15:1326033. https://doi.org/10.3389/fimmu.2024.1326033

  • Структура: https://www.rcsb.org/structure/2MLT - тетрамер меллитина с 4 $SO_4$ группами и молекулами $H_2O$

2.2. Сборка системы в CHARMM-GUI¶

Подготовка¶

Для сборки системы мы будем использовать CHARMM-GUI Membrane Builder

  1. Сайт CHARMM-GUI https://www.charmm-gui.org/ - заходим, регистрируемся с почты phystech.edu
  2. Input Generator > Membrane Builder

Step 0: Загрузка структуры белка¶

  • Выбираем PDB_ID

  • Выбираем нужные компоненты из нашей структуры: в данном случае, выбрана только цепь A (димер меллитина)

  • На следующей странице сохраняем все по-умолчанию

Step 1: Ориентация белка¶

На этом шаге нужно выбрать ориентацию белка (как он будет расположен в мембране)

  • Проверяем , что выбран димер меллитина (step1_pdbreader.pdb -> view structure)

  • В Orientation Options выбираем Align the pirst principal axis along Z - для простых пучков альфа-спиралей программа определит ось спирали и соотнесет ее с осью Z, перпендикулярной плоскости бислоя

Step 2: Определение размера и состава мембраны¶

Переходим на следующую вкладку и открываем структуру Oriented PDB: step2_orient.pdb

  • Здесь плоскостями отображена будущая поверхность мембраны.
  • Видим, что димер правильно ориентирован относительно нее.

Ниже можно посмотреть на площадь поперечного сечения димера вдоль вертикальной оси Z (перпендикулярной мембране)

Далее нужно выбрать состав и размер мембраны, в которую будет встроен белок.

  • Размер мембраны в плоскости XY зададим 60 А (что соответствует небольшому бислою ~50 липидов на монослой)

  • Состав - 100% липидов POPC

    • Бислой POPC - распространенный модельный бислой в случаях, когда мембрана используется только для создания нативного окружения мбранного белка, т.е. как "растворитель белка".
    • Когда важны свойства мембраны, например, когда они потенциально могут влиять на функционирование исследуемого белка, можно задавать более сложную композицию, схожую с нативным липидным окружением (например, плазматическая мембрана животных и т.д., см. Predefined Membrane в разделе https://www.charmm-gui.org/?doc=input/membrane.quick )

Проверяем заданную композицию кнопкой Show the system info

Step 3: Выбор растворителя¶

Посмотрим на "упаковку" системы в Packing Simulation: step3_packing.pdb. Здесь точками показаны будущие головки липидов, рамкой отмечен бокс (периодические граничные условия), можно увидеть периодические изображения белка. Важно убедиться, что периодические "изображения" белка находятся на достаточном расстоянии, чтобы не влиять друг на друга.

  • Далее можно выбрать метод, с помощью которого белок будет вставлен в бислой (оставляем по-умолчанию)
  • Также, на этом шаге выбирается растворитель. Часто выбирают 150мМ NaCl или KCl, основываясь на стандартных концентрациях ионов. При этом ионы добавляются таким образом, чтобы нейтрализовать суммарный заряд системы.

Типичные концентрации ионов

2.3. Расчет МД на кластере¶

Пайплайн уравновешивания¶

  • Цель уравновешивания: постепенно снять ограничения на движение атомов, чтобы избежать артефактов и "поломки" структуры после сборки.

  • Типы ограничений:

    • BB: позиционные ограничения на остов белка (backbone).
    • SC: позиционные ограничения на боковые цепи белка (sidechains).
    • wforce: позиционные ограничения на воду (обычно по оси Z).
    • tforce: позиционные ограничения на хвосты липидов (tails).
    • mforce: позиционные ограничения на головные группы липидов ("mid"/"headgroup").
    • ion: позиционные ограничения на ионы (Na+, Cl^-) — только на старте.

  • Позиционные ограничения прописывают в файлах топологий .itp, например, в файле PROA.itp:

    #ifdef POSRES
[ position_restraints ]
    1     1    POSRES_FC_BB    POSRES_FC_BB    POSRES_FC_BB   
    5     1    POSRES_FC_BB    POSRES_FC_BB    POSRES_FC_BB   
    8     1    POSRES_FC_BB    POSRES_FC_BB    POSRES_FC_BB   
...
#endif

  • В файлах параметров каждого из шагов уравновешивания (.mdp) в строчке define= указано, какие ограничения будут включены на данном шаге. Например, в файле step6.0_minimization.mdp:

    define = -DPOSRES -DPOSRES_FC_BB=4000.0 -DPOSRES_FC_SC=2000.0 -DPOSRES_FC_LIPID=1000.0 -DDIHRES -DDIHRES_FC=1000.0

Схема уравновешиания

  • На каждом цикле величина коэффициентов сил позиционных ограничений постепенно снижается:
  • Первый цикл: шаг интегрирования 1 фс, чтобы снизить риск ошибок интегратора на неравновесной системе. Далее dt становится 2 фс.

Запуск расчета¶

Рабочая директория с примером из семинара: /home/veretenenko/MolMod-2025/MELITTIN

Для запуска расчета на кластере нужно выполним следующие шаги:

  1. Копируем папку charmm-gui-xxx/gromacs в свою директорию на кластере
  2. Переделываем README в run.sh
    1. Прописываем параметры запуска (путь к Gromacs, номер GPU, число CPU):
      # на go
source /usr/local/gromacs-2024.4/bin/GMXRC
set GPU_ID      = 0 # номер GPU
set NT          = 10 # число ядер, которые займем под расчет
set PINOFFSET   = 0 # номер 1го ядра, с которого займем NT ядер
    2. Во все gmx mdrun добавляем флажки для МД на нужных ядрах и карточке
      -gpu_id $GPU_ID -nt $NT -pin on -pinoffset $PINOFFSET -pinstride 1 -nb gpu -bonded gpu -pme gpu -pmefft gpu -update gpu -cpi -cpo -cpt 15
    3. В production ставим set cntmax = 1 (т.к. будем считать одну траекторию)
  3. В файле step7_production.mdp выставляем нужную длину траектории: значения dt=0.002 (ps) и nsteps=500000 соответствуют $500000\cdot0.002=1000\ ps = 1\ ns$
  4. Запуск расчета:
    nohup ./run.sh &

def rmsf_from_calphas(ca):
    means = np.zeros((len(ca), 3))
    sumsq = np.zeros_like(means)

    for k, ts in enumerate(u.trajectory):
        sumsq += (k / (k + 1.0)) * (ca.positions - means)**2
        means[:] = (k * means + ca.positions) / (k + 1.0)

    return np.sqrt(sumsq.sum(axis=1) / (k + 1.0))

ca0 = u.select_atoms("segid seg_0* and protein and name CA")
ca1 = u.select_atoms("segid seg_1* and protein and name CA")

rmsf0 = rmsf_from_calphas(ca0)
rmsf1 = rmsf_from_calphas(ca1)

plt.figure(figsize=(6,4))
plt.plot(ca0.residues.resids, rmsf0, '.-', label="seg_0")
plt.plot(ca1.residues.resids - np.min(ca1.residues.resids), rmsf1, '.-', label="seg_1")

plt.ylim(0, 3.5)

plt.xlabel("residue number")
plt.ylabel(r"C$_\alpha$ RMSF (Å)")
plt.legend()
plt.tight_layout()
plt.show()
